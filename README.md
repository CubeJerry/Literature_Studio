# Literature_Studio
PhD Literature Collection.

The reading library and interactive knowledge map live in [docs/index.html](docs/index.html). No build step is required. To preview locally, serve the docs folder with `python -m http.server --directory docs`.

Publish using **Settings → Pages → Deploy from a branch → main → /docs → Save**. The project URL is https://cubejerry.github.io/Literature_Studio/ once deployed. The Pages site normally has a public audience even when its source repository is private. Private-repository Pages requires an eligible GitHub plan.

Browser notes do not move between domains. Export JSON on the original site, then import and restore the backup on the new site before editing. Restore replaces the notebook in that browser. New published papers belong in the embedded seed dataset; browser edits do not automatically commit to GitHub.
